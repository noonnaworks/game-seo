# 밝은 UI 개편 기록

이번 변경은 표현 계층에 한정했습니다. 데이터·본문·검수 상태·URL·기존 검사 코드는 바꾸지 않았습니다. 자동 검사를 통과한 것과 실제 화면 시각 검수를 완료한 것은 구분합니다.

## 수정 파일

| 파일 | 변경 |
| --- | --- |
| assets/style.css | 밝은 읽기 화면, 청록 포인트, 역할별 여백과 표면, 반응형·대비 개선 |
| scripts/views.mjs | 게임 바로가기, 간결한 허브, 핵심 답 우선, 검토 정보 하단 이동, 접힌 목차 |
| templates/layout.html | 헤더 운영자 문구 제거, 간결한 푸터. SEO head는 보존 |
| README.md | 최신 UI 구조와 이 기록 연결 |
| docs/UI_REDESIGN.md | 변경·검사·한계 기록 |
| dist/ | 기존 빌드로 HTML 5개와 CSS 등 배포 결과 재생성. 직접 수정하지 않음 |

## 요청 항목별 결과

1. 수정한 파일: 위 표. 신규 프레임워크·DB·라이브러리 추가 없음.
2. 유지한 기능: 기존 모든 URL, site.json 전체, 공략 본문, 검토일·플랫폼·관련 글·검토 근거, 내부 링크, 접근성, 404, npm build/dev, 검사 스크립트, Cloudflare 출력 구조.
3. 제거한 UI: 헤더의 운영자 메타, 상단 검토 경고·조건 박스, 펼쳐진 목차와 상세 메타의 과한 노출. 데이터는 삭제하지 않음.
4. 밝은 테마: 아이보리 배경·화이트 게임 선택 영역·짙은 차콜 본문. 네이비는 작은 헤더로 한정. 포인트는 청록 한 계열.
5. 정보 우선순위: 게임·공략 제목 → 짧은 설명 → 핵심 답 → 작은 검토 한 줄 → 목차와 실제 공략. 조건·플랫폼·근거는 하단.
6. 홈페이지: 간결한 브랜드 소개 다음 Once Human, 한국명·장르·실제 카테고리와 두 글의 바로가기. 그 아래 최근 공략. 가짜 통계·이미지·placeholder 없음.
7. 게임 허브: 게임 정보 → 실제 카테고리 링크 → 해당 공략 목록. 빈 카테고리 없이 바로 탐색.
8. 상세 페이지: 강한 H1, 짧은 기존 설명, 밝은 핵심 정리. 상단 검토는 한 줄만 표시하며 일부 확인 상태를 유지.
9. 카드: 게임 선택에는 흰색 표면과 얕은 그림자, 공략 선택에는 제목·태그·구분선, 답변에는 연한 청록, 주의에는 옅은 황색을 사용. 같은 박스 반복을 줄임.
10. 검수 정보: 적용 조건·플랫폼·전체 검토 범위·세부 출처·운영 정보는 하단 공식 자료 근처 details로 이동. 허위 ‘확인 완료’ 표시 없음.
11. 모바일: 760/520px 대응, 520px 이하 공략 한 열, 작은 H1, 여백 유지, 기본 접힌 목차, 긴 링크 줄바꿈. 실제 뷰포트 시각 검수는 미완료.
12. SEO: 변경 전 5개 페이지의 head 전체와 href 집합을 비교. title/description/canonical/Google verification/OG/Article·Breadcrumb JSON-LD 보존. sitemap·robots·인증 파일도 동일.
13. build: npm run build 통과. 기존 5개 HTML과 404·정적 파일을 같은 방식으로 생성.
14. check: node scripts/check.mjs 통과. 원문·검수 데이터·기존 스크립트 보존 비교도 통과. 두 글의 전체 검수 미완료 편집 경고는 유지.
15. check-preview: 정상 10개 경로, Content-Type, 301, 실제 404, 경계·숨김·잘못된 URL 6개 검사 통과.

## 추가 확인

- 본문 대비 11.35:1, 설명 5.03:1, 날짜 4.55:1, 링크 6.60:1, 답변 주의 문구 5.49:1, 검토 줄 4.57:1을 계산했습니다.
- 핵심 답이 본문보다 먼저, 적용 조건과 세부 검토 근거는 본문 뒤에 있는지 생성 HTML에서 검사했습니다.
- 스크린샷 없이 자연스러운 구성이며 기존 추상 SVG를 본문이나 카드에 새로 노출하지 않습니다. 설명용 figure 구조는 유지합니다.
- 원문을 유지하기 위해 본문의 기존 안내·요약 문구도 보존했습니다. 첫 안내 박스의 장식만 줄였습니다.
- CSS 모션 감소·키보드 초점·skip link·이미지 유동 폭·줄바꿈을 유지했습니다.

## 시각 검수의 한계

이 환경에서는 브라우저 접근이 제한되어 실제 Desktop/Tablet/520/360px 화면을 관찰하지 못했습니다. 따라서 ‘예쁘다’, ‘실제 가로 넘침이 없다’ 같은 시각적 자가검수 항목을 모두 통과했다고 기록하지 않습니다. 소스와 생성 HTML의 구조·대비·반응형 위험 검사 및 실제 HTTP 검사는 통과했지만, 실제 뷰포트에서 제목·답변·목차·출처를 마지막으로 확인해야 합니다. 이 작업에서 신규 배포나 콘텐츠 검수 완료 처리는 하지 않았습니다.
