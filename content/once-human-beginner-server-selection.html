01. 서버보다 먼저 시나리오를 확인하세요

Once Human은 먼저 시나리오를 선택하고, 그 시나리오 안에서 실제로 접속할 서버를 고르는 구조입니다.

  • 시나리오: 플레이 규칙과 콘텐츠가 달라지는 큰 게임 모드
  • 서버: 선택한 시나리오 안에서 실제로 접속하는 서버

따라서 처음 시작할 때는 서버 번호만 보기보다 먼저 어떤 시나리오에 속한 서버인지 확인하는 것이 중요합니다.

02. 처음이라면 터치 오브 스카이(초보자)

처음 플레이하면서 특별히 원하는 시나리오가 없다면 터치 오브 스카이(초보자)를 우선 확인하면 됩니다. 2026년 공식 서버 안내에서는 이 시나리오를 초보 플레이어에게 권장하고 있습니다.

일반 터치 오브 스카이와 이름이 비슷하지만 초보자용 시나리오는 별도로 구분됩니다. 공식 서버 목록에서는 초보자용 서버가 Manibus(Novice) 형태로 표시되는 사례도 확인할 수 있습니다.

처음 시작한다면

서버 이름만 보고 고르기보다 시나리오 이름과 초보자 또는 Novice 표시를 함께 확인하세요.

03. 같은 시나리오에 서버가 여러 개라면?

같은 시나리오 안에도 여러 서버가 열려 있을 수 있습니다. 기존 서버는 서버 진행도와 플레이어 성장 상태가 서로 다를 수 있습니다.

공식 안내에서는 신규 플레이어에게 추천 목록의 최신 서버를 우선 선택하도록 권장합니다. 그래서 특별한 이유가 없다면 아래 순서로 보면 됩니다.

  1. 현재 게임에 표시되는 추천 서버 목록을 확인합니다.
  2. 추천 목록 안에서 비교적 최근 서버를 우선 확인합니다.
  3. 서버 번호가 크다는 이유만으로 최신 서버라고 판단하지 않습니다.

서버 운영 상황은 계속 바뀔 수 있으므로 최종 선택은 현재 게임 화면의 추천 목록을 기준으로 하세요.

04. 친구와 같이 한다면 친구 서버가 우선입니다

친구가 이미 Once Human을 플레이하고 있다면 최신 추천 서버보다 친구가 있는 정확한 서버를 먼저 확인하세요.

친구에게 다음 세 가지를 확인하면 됩니다.

  1. 같은 지역인지
  2. 친구가 플레이하는 시나리오가 무엇인지
  3. 친구의 정확한 서버명이 무엇인지

시나리오 이름만 같아도 실제 서버가 다르면 바로 같은 공간에서 플레이할 수 없습니다. 서버가 가득 찬 경우에는 친구의 특별 초대 코드가 필요한 경우도 있습니다.

친구와 같은 서버에 접속하는 전체 과정은 친구와 같은 서버 들어가는 방법에서 자세히 확인할 수 있습니다.

05. 콘솔 서버는 표시를 확인하세요

Once Human에는 크로스 플랫폼 서버와 콘솔 전용 서버가 있습니다. 서버명에 〖Console〗 표시가 붙어 있다면 콘솔 전용 서버입니다.

콘솔 전용 서버는 콘솔 기기에서만 접속해 플레이할 수 있습니다. PC·모바일·콘솔 등 서로 다른 플랫폼의 친구와 함께 플레이할 계획이라면 크로스 플랫폼 서버인지 확인하세요.

06. 서버 선택 전 체크리스트

혼자 처음 시작한다면

  • 터치 오브 스카이(초보자)인지 확인
  • 현재 추천 서버 목록 확인
  • 추천 목록 안에서 최신 서버 우선
  • 콘솔 전용 서버가 필요한지 확인

친구와 같이 시작한다면

  • 같은 지역인지 확인
  • 같은 시나리오인지 확인
  • 정확한 서버명이 같은지 확인
  • 서버가 가득 찼다면 특별 초대 코드 확인
한 줄 결론

혼자 처음 시작한다면 터치 오브 스카이(초보자)의 추천 최신 서버를 우선 확인하고, 친구가 이미 플레이 중이라면 친구의 정확한 서버를 맞추는 것이 먼저입니다.
